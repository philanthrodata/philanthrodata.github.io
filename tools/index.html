How I protect your data

You don’t have to trust me. You can check.

Most data tools ask you to upload your donor list to their servers. Ours can’t: there’s no server to send it to.

Nothing is uploaded

Your file is read by your own browser. Open your browser’s developer tools while you run a check and you’ll see no network requests.

It works with Wi‑Fi off

Load the page, turn off Wi‑Fi, then run the check. It still works, because nothing needs to leave your computer.

Export only what’s needed

Names, contact fields, and last gift date are enough. Leave notes, wealth screening, and giving details out of the file.

I built these tools so a small nonprofit can find the money it’s losing in an afternoon, without a data hire or a new vendor contract.
